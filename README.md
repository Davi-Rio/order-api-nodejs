# Order API

API desenvolvida em **Node.js (NestJS)** para gerenciamento de pedidos.

O projeto implementa um CRUD completo de pedidos com persistência em **PostgreSQL**, documentação via **Swagger** e autenticação **JWT**.

---

# Tecnologias utilizadas

- Node.js
- NestJS
- TypeScript
- PostgreSQL
- TypeORM
- Swagger (OpenAPI)
- JWT Authentication
